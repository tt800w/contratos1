# Reglas de Git Commits

- **Commits atómicos**: Realizar commits independientes y específicos por cada función agregada o corrección realizada.
- **Prohibido commit único masivo**: No agrupar múltiples funciones o correcciones no relacionadas en un solo commit.
- **Staging granular**: Usar `git add <archivo>` o fragmentos puntuales para incluir únicamente los cambios pertinentes al commit actual.
- **Mensajes claros y descriptivos**: Describir con precisión la función o corrección (siguiendo convenciones como `feat:`, `fix:`, `refactor:`).
